# PROJECT RULES — «Погода» (Android, Jetpack Compose) по референс-видео

## СУТЬ
Погодное приложение из refs/ (кадры моего видео). карточки, премиум, реклама,
облака-пальцем, модалка про траву). 

## ГРАНИЦЫ
Пишу только в этом воркспейсе. refs/ и refs_src/ не модифицировать (только читать/резать в refs/).

## ИСТОЧНИКИ ПРАВДЫ
1) refs/*.png — UI: состав экранов, порядок карточек, подписи RU, цвета (голубая и тема, которая выпадает с рулетки).
2) open-meteo.com — данные: current/hourly/daily, geocoding, WMO-коды погоды.
   ДОКУМЕНТАЦИЮ ЧИТАТЬ ЧЕРЕЗ ВЕБ-ПОИСК перед написанием клиента. API-ключей нет и не надо.
3) Jetpack Compose / Material3 docs — через веб-поиск, не по памяти.

## ТЕХ
Kotlin + Compose + Material3, minSdk 24, Gradle Kotlin DSL, kotlinx.serialization.
Кэш последней погоды (DataStore) + баннер «нет сети». Гео по умолчанию Санкт-Петербург, потом Москва, поиск городов.

## РОЛИ И СУБАГЕНТЫ (СТРОГО ЧЕРЕЗ invoke_subagent)
Главный агент — Оркестратор проекта. Он координирует задачи и распределяет работу по специализированным субагентам.

### 1. Написание кода (Кодеры):
- `ui-coder` — верстка Jetpack Compose по refs/*.png, карточки, шрифты, темы Material3, анимации («облака пальцем», рулетка тем), модалки.
- `data-coder` — сетевой слой Open-Meteo API, кэширование DataStore, оффлайн-детекция, переключение городов, ViewModels.

### 2. Сборка и деплой на физический телефон:
- `device-qa` — gradlew assembleDebug, adb install на Sony G8342, adb shell screencap в shots/.

### 3. Тестирование и критика (Приемка):
- `feature-qa` — тестирование сценариев: Open-Meteo, DataStore кэш, оффлайн-баннер, поиск городов, сбор logcat.
- `ui-critic` — сверка скриншотов shots/ с refs/: блоки, порядок, тексты RU, тема.
- `ref-critic` — строгий финальный аудит 1-в-1 по кадрам refs/ и оригинальному видео refs_src/.

### ПРАВИЛА ПРИЕМКИ ФАЗЫ:
1. Главному оркестратору ЗАПРЕЩЕНО собирать APK и дергать adb через run_command (это делает ТОЛЬКО `device-qa`).
2. Главному оркестратору ЗАПРЕЩЕНО объявлять фазу готовой без отчетов от субагентов.
3. Конец фазы = артефакты: скриншоты с устройства в shots/, путь APK, вердикты PASS от QA и критиков.
