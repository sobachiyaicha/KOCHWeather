# КОЧWeather

Перегруженное говном погодное приложение для Android на Kotlin + Jetpack Compose. Сделано как «погода,
в которую никогда не хочется заходить»: встроеное казино, реклама каждые 20–30 секунд, премиум подписка,
ии факты, оценка поогоды и полу-интеграция сервисов яндекса с карточками на пол экрана!

Работает без VPN, без аккаунтов и без API-ключей (почти). Если данных нет — пишет «Нет данных»,
а не рисует красивые цифры из головы.

APK версии 1.1 — в разделе [Releases](../../releases).

## Что нового в 1.1

- **Казино переделали.** Тёмная карбоновая панель, сундук с лучом света и свечением по редкости,
  большая кнопка «ОТКРЫТЬ», карточка приза и надпись **«ВЫПАЛО:» / «ВЫПАЛА:»** — по роду приза,
  потому что «выпал мать с окна» это уже перебор.
- **Первые призы не случайны** (как и всё хорошее в этой жизни): мать с окна (100 %),
  бессрочный контракт на сво, сын мияги из окна, шанс на додеп. Дальше — везение.
- **Пять бесплатных попыток**, потом только «Смотреть рекламу → +1 попытка». Шанс на додеп
  тоже даёт попытку, так что можно страдать бесконечно.
- **История дропов** съехала в аккордеон, закрытый по умолчанию: меньше поводов смотреть,
  что тебе опять выпала лужа.
- **Кофе и промокоды удалены.** Совсем. Их больше нет ни в призах, ни в коде, ни в тестах.
- **Реклама** вылетает после стирания облачков, крестик появляется через 3 с на фото и через 5 с
  на видео, половина показов — ролики, один и тот же креатив дважды подряд не выпадает.
- **Облачка** возвращаются каждые 20–30 секунд. Да, это раздражает. Так и задумано.
- **Факт дня** наконец меняется при перезапуске (раньше он был прибит к городу и дню).
- **Зонт** теперь с роликом и звуком, а видео листается без паузы и перемотки — как реклама
  в метро, только хуже.
- **Фон по умолчанию** — пёс без блюра. «Изумрудный лес» удалён, «Кровавый закат» остался
  на одном градиенте, потому что обои там были лишние.
- **Приложение больше не вылезает на экране блокировки** и не будит телефон. Извини.

## Данные

| Что | Источник |
| --- | --- |
| Прогноз | [MET Norway](https://api.met.no/) — основной |
| Фолбэк | Open-Meteo, затем 7timer |
| Кэш | DataStore, последний успешный прогноз |
| Карта | osmdroid + тайлы OpenStreetMap |
| Такси | тарифы Яндекс Go, deep link `yandex-taxi://` |

## Сборка

Нужны JDK 17 и Android SDK (compileSdk 36).

```bash
./gradlew :app:assembleDebug        # debug
./gradlew :app:assembleBenchmark    # release-подобная сборка (R8, не debuggable)
```

Ключ для источника пробок необязателен: создайте `local.properties` со строкой

```properties
TRAFFIC_API_KEY=...
```

Без ключа приложение показывает «Нет данных о пробках», а не нули.

Тесты — `app/src/test`: 38 сьютов, 238 тестов (парсеры, политики, репозитории, лутбокс,
русские тексты, отсутствие эмодзи в UI).
