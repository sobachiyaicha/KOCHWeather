## feature-qa (функциональные сценарии)

Пройти по 14 пунктам на установленном APK и по регрессии Фазы 4 (R1–R23 из `ACCEPTANCE.md`):

1. Навбар на всех вкладках: «Главная» → «Карта» → «Список» → «Поиск» → «Вид» → обратно;
   бар виден и кликабелен на каждом, активный таб подсвечен, контент не уезжает под бар.
2. Свайп по ленте меняет город и **анимирован**; после анимации данные соответствуют городу
   (проверить СПб → Москва → СПб, температуру/название).
3. «Список» → «+» → поиск → «Казань» → добавлен, выбран, погода загрузилась; дубль не добавляется.
4. Заголовок: СПб — «ТЕКУЩЕЕ МЕСТО», любой другой город — «ВЫБРАННЫЙ ГОРОД».
5. Лутбокс: открывается, есть сундук; «Открыть» → анимация → приз; повторные открытия не
   ломают состояние; история дропов сохраняется после перезапуска приложения.
6. Погодный приз: если в прогнозе на завтра дождь/снег — текст «Вам выпал дождь/снег на завтра»;
   если прогноза нет — погодный приз не выпадает (не выдумывать).
7. Реклама: два открытия подряд дают разные креативы (или смену при следующем дне);
   CTA ведёт в свою функцию (пейволл/лутбоксы/зонты/еда); есть «Реклама …» и пояснение про премиум.
8. Осадки: сегмент «Осадки» показывает мм/ч (столбики) и сумму; при отсутствии данных — честное
   «Нет данных об осадках»; деталь дня показывает мм, если есть.
9. Такси: цены трёх тарифов зависят от выбранной точки (переключить 2 точки — цены разные),
   минимум 149/205/349 ₽, при «нет данных о пробках» — без наценки; нет `BYN`.
10. Тема: переключить 2–3 темы — фон локальный, без сетевых плейсхолдеров, читаемость текста.
11. Валюта/город: нигде нет `BYN`, «Минск», «Беларусь» (в UI и в данных); премиум 179 ₽,
    старая 899 ₽; зонты в рублях; билеты без Минска.
12. Совет/факт: «А знали ли вы…» меняется (перезапуск/обновление/следующий день);
    совет по одежде отличается для разных городов/дней.
13. Оценка погоды: нет кнопки «Развернуть», средняя оценка и звёзды на месте, оценка ставится.
14. Регресс Фазы 4: кэш/офлайн-баннер, «Повторить», поиск ≤12 с, deep links Яндекс Go/Еда,
    карта с маркером, облачная вуаль один раз за сессию, модалка травы, премиум без автопокупки,
    отсутствие эмодзи, «нет данных» вместо выдумок.

Отдельно: `logcat` без `FATAL`/`ANR`/`AndroidRuntime`; приложение не падает при быстрых
переключениях вкладок и при повороте экрана (если не запрещён).
