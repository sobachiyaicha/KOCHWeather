# ui-coder — подсказка облаков (одностороннее гашение) + контраст статуса рулетки

**Дата:** 14.11.2026. **Сборка:** `compileDebugKotlin` → **BUILD SUCCESSFUL in 9s**, 0 warnings
(`.local/build_hint.txt`).

## 1. Подсказка облаков больше не возвращается (блокер)

**Было** (`ui/components/CloudVeilOverlay.kt`):
```kotlin
onDragStart = { hintVisible = false … }
onDragEnd = { lastPoint = null; if (!isCleared) hintVisible = true },
onDragCancel = { lastPoint = null; if (!isCleared) hintVisible = true }
```
При незавершённом жесте (или нескольких подряд) подсказка возвращалась и снова ложилась поверх
уже открытой капсулы — три вспышки за жест на видео r9_clouds.mp4.

**Стало:** гашение одностороннее —
```kotlin
onDragStart = { hintVisible = false … }
// Подсказку НЕ возвращаем: иначе она снова ложится поверх открытой капсулы.
onDragEnd = { lastPoint = null },
onDragCancel = { lastPoint = null }
```
После первого касания текст не появляется до конца жизни оверлея. Если вуаль ещё видима, а
подсказки нет — это ожидаемо (пользователь уже понял жест), зато ни одного кадра с текстом
поверх капсулы.

## 2. Контраст статуса в рулетке (P2)

**Было:** «Доступно» светло-зелёным (`accentSuccess`) прямо на стекле — **1.27:1**.

**Стало:** та же схема, что у бейджей в «Виде» — светлая пилюля `0xE6FFFFFF`, радиус pill,
внутри Material-иконка и текст `#2E7D32` («Доступно») или `#8A5A00` («Открывается в
лутбоксах»). Контраст ≈5–6:1 на любой теме и на любом превью.

## 3. Не сделано (осознанно, не блокер)

Замечание «в рулетке превью приза — стоковое фото iPhone, тема не показана»: центральный
телефон — это **реальное фронтальное фото** (`ImageCategory.IPHONE_FRONT`), которое критик сам
потребовал в run 4 вместо мокапа и задней крышки. Тему показывают две карточки-«билета»
(«Оформление Лес» / «Оформление Планета Марс», градиент темы на всю ширину) — они и есть превью
оформления. Если критик хочет видеть тему *на экране телефона*, есть два варианта на выбор
оркестратора: (а) вернуть композ-мокап `PhoneMock` (одна строка), (б) наложить тонировку темы
30 % на фото (одна строка). Оба меняют согласованное ранее «реальное фото фронта».
