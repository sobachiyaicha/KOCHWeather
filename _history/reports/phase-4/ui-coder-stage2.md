## 1. Шрифт Inter (OFL)

- Скачаны **статические TTF** 400/500/600/700 через Google Fonts CSS с legacy-UA (Android 4.3):
  `res/font/inter_{regular,medium,semibold,bold}.ttf` (по ~326 КБ, всего +1.3 МБ APK).
- Покрытие проверено по `cmap` (парсер в `.local/font/check_cmap.py`): 2818 глифов, есть
  А-я, Ё, №, °, ★, →, ›, −, — (кириллица полная, без подмены на системный).
- Лицензия: `app/src/main/assets/fonts/Inter-OFL.txt`.
- `KochType.Family = KochFontFamily`; 800 маппится на Bold-файл. Системный шрифт больше нигде
  не задаётся вручную: все новые экраны используют `KochType.*`.

## 2. Главная (порядок и материалы)

| Тема | Порядок блоков |
|---|---|
| **BLUE_SKY** (refs/clean_main.png, bottom_nav) | шапка → «Погодные условия» (5 сегментов + **hourly всегда развёрнут** + «Оцените погоду» с «Развернуть») → 10 дней (зонтики **сразу после «Пн»**) → сервисы 2×2 → AI-факт → премиум → реклама |
| **остальные** (theme_copper, f_063/f_080) | шапка → AI-факт → премиум → реклама → сервисы 2×2 → «Погодные условия» → 10 дней |

Что переделано:
- **AI-факт** — без плашки: искра 14 dp + «А знали ли вы...» 12/500 + строка факта 12/400
  по центру (как в refs/premium_ads.png).
- **Премиум** — стеклянная карточка: текст слева, синяя капсула «Подписка Премиум / 5.99 BYN /
  29.99» справа; купленный статус — зелёная капсула «★ ПРЕМИУМ».
- **Реклама** — зелёный градиент `accentAd*`, метка «РЕКЛАМА» `accentAdLabel` без чёрной плашки,
  **фото справа во всю высоту** (104 dp, `RectangleShape`), текст слева.
- **Сервисы 2×2** — без фото внутри карточек (фото Дубая переехало героем в «Билеты»):
  глиф 16 dp + лейбл, заголовок 14/600, описание до 3 строк; чипы такси/еды — пилюля с кружком
  и стрелкой (никаких `->`). Карточки в ряду выровнены по высоте (`IntrinsicSize.Min` +
  `fillMaxHeight`), тексты не обрезаются.
- **Шапка** — капсула `capsuleFill` с верхним бликом и кантом 0.8 dp, город всегда `displayCity`
  (адаптивный кегль по длине строки удалён), `Макс./мин.` — токен `caption`.
  **Температура не тронута**: `rotate(-15f)`, `offset(-12, -24)`.
- **Оценка** — звёзды в пилюле (18 dp, `accentStar`), «Развернуть ⌄» относится к блоку оценки
  и раскрывает подпись («В среднем сегодня: 3.5 ★» / «Ваша оценка: N ★» / «Спасибо за отзыв!»).
- **10 дней** — строки 6 dp паддинга, бар 4 dp, зонтики после «Пн»: «Зонтики от **29.99 BYN**
  Смотреть ›» (синяя ссылка не нужна, цена — `accentPromo`).

## 3. Облака и статус-бар

`CloudVeilOverlay` переписан:
- вуаль закрывает **только верхние 45 %** (шапку), мягкий нижний край (градиент в прозрачность),
  ниже — ничего; 4 мягких овала вместо 12 плоских кругов на весь экран;
- **удалены** прогресс-бар, «Сотрите облака: 0 %» и нижняя подпись «Погода спрятана за облаками»;
- подсказка — рука 22 dp + две строки 16/600 тёмным `#1F2A33` по облаку, без плашки;
- жест по-прежнему перехватывает drag над шапкой (город не переключается), порог стирания
  700 dp, стирание только внутри облачной зоны;
- **статус-бар**: `WindowCompat` выставляет `isAppearanceLightStatusBars` по яркости `bgTop`
  (тёмные иконки на голубой/медной, светлые — на тёмных темах). «Белым по белому» больше нет.

## 5. Фото из новых категорий (data-coder)

- **Рулетка**: `ImageCategory.IPHONE_FRONT` в `PhonePreview`, `ContentScale.Crop`, 132×190;
  `RemotePhoto` получил параметр `fallback` — при загрузке/ошибке показывается **фронтальный
  мокап темы**, а не серая заглушка. Задняя крышка не используется.
- **Еда**: явная таблица `id → ImageCategory`:
  `f_big_hit → FOOD[0]`, `f_pepperoni/f_cheese_chicken → FOOD[1]`,
  `f_flat_white → FOOD_COFFEE`, `f_croissant → FOOD[3]`, `f_fries → FOOD_FRIES`,
  `f_nuggets → FOOD_NUGGETS`, `f_cherry_pie → FOOD_PIROSHKI`, `f_dodster → FOOD_HOTDOG`,
  `f_bumble → FOOD_COFFEE`. Нет URL — плейсхолдер; бургер никуда не подставляется.
  `FoodBottomSheet` теперь принимает `photoUrls: Map<ImageCategory, List<String>>`.

  В `benchmark`/`release` (`isDebuggable = false`) `BuildConfig.DEBUG = false`, оверлей не
  компонируется вообще.
- **Шрифт:** оставлены 4 веса (400/500/600/700), 800 → Bold.

## 8. Что осталось / риски

1. `device-qa`: `assembleDebug`, install на G8342, **холодный старт** (ANR-фикс data-coder
   проверить после этих правок), свежие `r2_*` — главная (обе темы), облака, рулетка, список,
   поиск, вид, карта, еда, билеты.
2. APK вырос на ~1.3 МБ из-за четырёх начертаний Inter — если критично, можно оставить
   400/600 и маппить 500/700 на них (−0.65 МБ).
3. Превью тем — градиенты (фото леса/Марса в каталоге нет); если `data-coder` добавит
   `THEME_FOREST/THEME_MARS`, `ThemeCard` подставит фото одной строкой.
4. `CityPickerDialog.kt` и `FullScreenScaffold.kt` больше не используются — можно удалить
   отдельным коммитом, чтобы не путать ревьюера.
5. Облачная вуаль: если wipe-жест покажется тугим на устройстве, порог 700 dp → 550 dp.
