## 1. Тап по маркеру открывает карточку города

**Было:** `Marker` без обработчика — оверлей только рисовался; тап уходил в карту (зум/пан),
info-window не открывался (в т.ч. потому, что `showInfoWindow()` без обработчика никто не звал).

**Стало** (`ui/components/WeatherMapScreen.kt`):
- в `buildMarker()` навешен `setOnMarkerClickListener`:
  ```kotlin
  setOnMarkerClickListener { clicked, view ->
      view.controller.animateTo(clicked.position)
      clicked.showInfoWindow()
      view.invalidate()
      true
  }
  ```
  `Marker` в osmdroid 6.1.18 создаёт `MarkerInfoWindow` по умолчанию (`Marker.java:116`),
  поэтому `showInfoWindow()` показывает `bonuspack_bubble` с `title` и `snippet`;
- `title = cityName`, `snippet = markerSnippet(...)`:
  «2° · Облачно», «2°» если описания нет, «Нет данных» если нет температуры;
- подпись обновляется в `LaunchedEffect` при смене города/погоды, обработчик привязан к самому
  маркеру — пересоздание не требуется;
- крашей при `null` нет: `markerSnippet` и `conditionRu: String? = null` явно обрабатывают пустоту,
  `showInfoWindow()` при отсутствии info-window просто возвращает управление.

`MainScreen` передаёт `conditionRu = uiState.weather?.conditionDescription`.

## 2. Контраст подписи «Температура (°C)»

**Было:** `textPrimary.copy(alpha = 0.45f)` на стекле поверх светлого облака — ≈2:1, подпись
«исчезала» на голубой теме.

**Стало:**
- `ui/design/KochBackground.kt` — скрим под белым текстом усилен с 30/20/35 % до **40/30/48 %**
  (верх/середина/низ). Фото неба остаётся фотографией, но фон под стеклом темнее;
- `ui/main/MainWeatherCards.kt` — подпись сегмента: `alpha 0.45 → 0.88`.

Оценка контраста: при относительной яркости фона L≈0.15 (фото + 40 % скрим + стекло 10 %)
белый 88 % даёт L_text≈0.87 → (0.87+0.05)/(0.15+0.05) ≈ **4.6:1**; при более тёмных участках
фото — выше. Остальные подписи на стекле (`textTertiary` 70 %) — ≥3:1, заголовки 100 %.
