## F-1 (P0) Статус-бар над фото-небом

**Было:** `useDarkStatusIcons = bgTop.luminance() > 0.35f` — на тёмном фото неба (после скрима
40/30/48 %) включались **чёрные** иконки: 1.18:1 (голубая) и 1.37:1 (медная).

**Стало** (выбран вариант «светлые иконки + верхний скрим», он не зависит от конкретного фото):
- `KochSkyBackground(..., onPhotoLoaded)` сообщает наверх, загрузилось ли фото;
- `MainScreen`: `useDarkStatusIcons = veilVisible || (!skyPhotoLoaded && bgTop.luminance() > 0.35f)`
  → **над фото — белые иконки**, под облаками (светлые облака) — тёмные, на gradient-фолбэке —
  по яркости темы (голубая/медная светлые → тёмные);
- в `KochSkyBackground` добавлен **верхний скрим** 32 dp `0x73000000 → transparent` поверх фото.
  Белый значок на фоне `фото + 45 % чёрного` даёт ≈7–10:1.

Итог по состояниям:

| Состояние | Иконки | Почему |
|---|---|---|
| Фото неба загружено, вуали нет | белые | верхний скрим 45 % |
| Вуаль облаков | тёмные | облака светлые |
| Офлайн/фолбэк, голубая или медная | тёмные | фон градиента светлый (luminance ≈0.42–0.44) |
| Тёмные темы (киберпанк и т.п.) | белые | bgTop тёмный |
