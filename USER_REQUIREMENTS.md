# Требования и указания пользователя — KOCHWeather («Погода 2025»)

## 1. Что за проект

- Название **KOCHWeather**, applicationId `com.koch.weather`, Kotlin + Jetpack Compose + Material3.
- Сатирическое погодное приложение «Погода 2025» по референс-видео: карточки (Дубай, лутбоксы,
  такси, еда), премиум-пейволл, рекламный баннер, выпадение тем из лутбоксов, жест «прогони
  облака пальцем», модалка «про траву», нижний таб-бар на 5 разделов.
  (В референсе цена была 5.99 BYN; в Фазе 5 по требованию пользователя переведено на рубли —
  179 ₽ за год, старая 899 ₽.)
- Гео по умолчанию: Санкт-Петербург, затем Москва, плюс поиск городов.
- Всё в приложении и в переписке — **по-русски**.
- Офлайн: кэш последнего прогноза в Jetpack DataStore + баннер «нет сети».

## 2. Правила работы (из брифа и AGENTS.md)

1. Главный агент — **только оркестратор**: планирует, распределяет, отчитывается.
   Код не пишет, APK не собирает, `adb` не дёргает.
2. Роли: `ui-coder`, `data-coder` (код) → `device-qa` (сборка/устройство) →
   `feature-qa` + `visual-critic` + `code-reviewer` (+ `perf-qa` для релиза) → `judge`.
3. Три жёстких запрета: оркестратору нельзя собирать APK/дёргать adb; нельзя отдавать
   результат в обход `judge`; конец фазы = PASS от `judge` + свежие `shots/` + логи + ноль багов.
4. После каждой фазы — СТОП до «ок». Один коммит на фазу, сообщения на английском
   вида `Phase 4: ...`.
5. «Готово» словами не считается: нужны скриншот с телефона, путь APK и логи.
6. Не нашёл ответ — сначала веб-поиск и grep по воркспейсу, только потом вопрос пользователю.
7. Отчёты ролей — файлами в `_history/reports/phase-N/<role>.md`; `judge` читает файлы.
